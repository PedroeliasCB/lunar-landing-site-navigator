# Skill: Frontend Design & UI Engineering
1. **Dirección Visual Clara:** Define antes de codificar una paleta coherente (ej. Dark Mode técnico para telemetría/ingeniería o Clean Light para analítica), tipografía legible (Inter / JetBrains Mono para datos) y jerarquía visual estricta.
2. **Componentes Orientados a Datos:** Incluye siempre estados de carga (skeletons), estados vacíos (empty states) informativos, KPIs destacados en la parte superior y gráficos interactivos (Recharts, Deck.gl, Plotly).
3. **Cero Fricción:** La aplicación debe abrir directamente en el dashboard o herramienta principal con datos precargados listos para interactuar en menos de 2 segundos.
4. **Responsividad:** Asegura compatibilidad tanto en escritorio como en pantallas móviles mediante grids adaptables de Tailwind.
